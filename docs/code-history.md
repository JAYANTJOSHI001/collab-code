# Code History

One of the most powerful features of **Collab** is its ability to **track the complete history of code changes** during a session. With multiple collaborators working on the same file simultaneously, having a clear record of previous versions is essential. Collab automatically manages and stores these changes, allowing users to **review, compare, and revert** to earlier code states effortlessly.

---

### 🔄 How Code History Works

When you or your collaborators modify a file, **Collab creates a new version snapshot** in real time. These snapshots are stored sequentially and are accessible through the **Code History** panel.

This ensures:

- 🔹No code is ever truly lost.
- 🔹You can revert to previous working versions.
- 🔹You can **compare versions** to identify what changed and when.

---

### 🛠️ Accessing Code History

To check code history:

- 🔹On the **left sidebar**, click the **History icon** (located above the file explorer).
- 🔹A **Code History panel** will open on the right-hand side of the screen.
- 🔹Inside the panel, you will find two viewing modes:
    - - 🔹**List View** – Browse through a chronological list of all saved code versions.
    - - 🔹 **Diff View** – Select any two versions to visually **compare changes** (similar to Git diffs).

---

### 👁️ Use Cases

- 🔹 Revert accidental deletions or overwrites.
- 🔹 Understand what a collaborator changed.
- 🔹 Trace bugs or regressions introduced in recent edits.
- 🔹 Use it as a real-time alternative to Git for quick code recovery.

---

### 📝 Note

While Git remains the authoritative version control tool, **Collab's internal versioning system complements Git** by providing quick, session-level history without requiring staging or committing.

---

Collab ensures **code safety and traceability** — even in fast-paced, collaborative environments. Remember to check your history before assuming any change is lost!
