# Committing Your First Code

Committing changes is a critical step in the development workflow—and **Collab** makes it simple and intuitive.

You can commit your changes directly within the platform after editing or collaborating, eliminating the need to switch to a separate Git interface.

---

### 📝 How to Commit Code in Collab

- 🔹**Click on the "Commit" Button** in the top-right corner of the editor interface to open the commit panel.
- 🔹**View the Commit Panel** that appears on the **right-hand side** of your screen, showing all modified files in your working directory.
- 🔹**Write a Commit Message** that briefly describes your changes—e.g., `"Fix header bug and update styling"`.
- 🔹**Select Files to Commit** by using the checkboxes. Only selected files will be included in the commit.
- 🔹**Click "Commit Changes"** to save your changes to your current Git branch after writing your message and selecting files.

---

### ✅ Important Notes

- 🔹You can commit **multiple files together** or commit individual files selectively.
- 🔹All commit actions are tied to your GitHub account via OAuth2, ensuring secure and trackable version history.
- 🔹You must have write access to the repository to commit changes.

---

### 🚨 Don't Forget

Before ending your session, **always commit your work** to avoid losing unsaved progress. Uncommitted changes may not persist across collaborative sessions or reconnects.
